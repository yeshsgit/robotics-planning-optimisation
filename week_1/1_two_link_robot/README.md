连杆机器人运动学仿真器 (2-Link Robot Arm Kinematics Simulator)这是一个基于 Python 的 2 连杆平面机器人手臂交互式仿真程序。该项目展示了机器人学中的核心概念：正向运动学 (FK) 和 逆向运动学 (IK)，属于“机器人规划与优化”课程轨道。🚀 功能特性实时交互：点击工作空间内的任意位置，机械臂将实时移动。逆向运动学 (IK)：使用几何法（余弦定理）精确计算关节角度 ($\theta_1, \theta_2$)。多解展示：同时显示 肘部向上 (Elbow Up) 和 肘部向下 (Elbow Down) 两种可能的配置。正向运动学 (FK)：根据计算出的角度渲染机器人的物理状态。实时数据监控：侧边栏专用面板，以度（Degrees）为单位实时显示目标坐标和关节角度。工作空间验证：自动检测目标点是否超出机械臂的可达范围。🛠️ 环境要求Python 3.xNumPy（用于矩阵运算和三角函数计算）Matplotlib（用于交互式 GUI 和图形渲染）安装依赖库：Bashpip install numpy matplotlib
📂 项目结构main.py：包含 RobotArmIK 类和所有仿真逻辑的核心脚本。README.md：项目文档及数学背景介绍。📖 数学原理正向运动学 (Forward Kinematics, FK)已知关节角度 $\theta_1$ 和 $\theta_2$，末端执行器的位置 $(x, y)$ 通过累加各连杆的向量得到：$x = L_1 \cos(\theta_1) + L_2 \cos(\theta_1 + \theta_2)$$y = L_1 \sin(\theta_1) + L_2 \sin(\theta_1 + \theta_2)$逆向运动学 (Inverse Kinematics, IK)已知目标位置 $(x, y)$，通过 $L_1$、$L_2$ 与目标点距离 $d = \sqrt{x^2 + y^2}$ 组成的三角形，利用 余弦定理 求解关节角。求解 $\theta_2$：$$\cos(\theta_2) = \frac{x^2 + y^2 - L_1^2 - L_2^2}{2 L_1 L_2}$$求解 $\theta_1$：$$\theta_1 = \operatorname{atan2}(y, x) - \operatorname{atan2}(L_2 \sin\theta_2, L_1 + L_2 \cos\theta_2)$$🎮 使用方法运行脚本：Bashpython main.py
